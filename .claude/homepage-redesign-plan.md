# ZENdian 主页与项目系统重构方案

## 📋 现状诊断

### 当前架构分析

**项目文件结构规范**（已实现）:
```
{类型文件夹}/
  └── {项目名}/
      ├── 00 控制台/
      │   ├── {项目名}.home         ← JSON 控制台数据
      │   ├── Overview.md          ← 项目概览
      │   └── Timeline.md          ← 任务时间线
      ├── 10 笔记流/
      ├── 20 工作区/
      ├── 30 交付物/
      ├── 90 资源库/
      └── 91 附件/
```

### 核心问题清单

#### 🔴 严重问题（阻碍可用性）

1. **主页功能不完整**
   - ❌ 每日回顾：环形进度条数据来源不明确，检查列表只是占位符
   - ❌ 待办系统：与项目系统割裂，无法关联到具体项目
   - ❌ 便签功能：刚实现基础增删，无编辑、无富文本、无分类
   - ❌ 热力图：只统计修改次数，缺少活动类型区分（创建/编辑/完成任务）
   - ❌ 本月数据：趋势图是假数据，没有真实历史统计

2. **项目主页功能缺失**
   - ✅ 项目列表扫描（已有）
   - ❌ 项目状态管理：只有进度百分比，缺少「进行中/暂停/完成/归档」状态
   - ❌ 项目详情面板：信息过于简单，缺少关键元数据
   - ❌ 项目间关联：无法标记依赖关系、里程碑、标签
   - ❌ 快速筛选：无状态/类型/标签筛选器

3. **项目控制台（.home 文件）功能不足**
   - ✅ 任务列表（已有）
   - ✅ 交付物列表（已有）
   - ✅ 最近文件（已有）
   - ❌ 缺少里程碑追踪
   - ❌ 缺少项目统计面板（时间消耗、文件数、协作者）
   - ❌ 缺少快速跳转到工作区/笔记流的入口优化

#### 🟡 中等问题（影响体验）

4. **UI 设计问题**
   - 📐 主页 12 列网格布局固定，响应式不足
   - 🎨 项目卡片样式单一，信息密度低
   - 🔲 控制台视图过于朴素，缺少视觉层次
   - ⚠️ 空状态提示不友好（"暂无数据"太冷冰）

5. **交互逻辑问题**
   - 🖱️ 待办点击直接跳转文件，无快速勾选（需要打开文件才能标记完成）
   - 🔄 项目列表无拖拽排序
   - ⌨️ 缺少键盘快捷操作
   - 📱 移动端适配未考虑

6. **数据一致性问题**
   - 🔗 Timeline.md 的任务与 .home 文件的任务不同步
   - 📊 进度计算逻辑混乱（有的基于 .home tasks，有的基于 Timeline.md）
   - 🗂️ 项目描述可以在 .home 和 Overview.md 两处编辑，容易冲突

---

## 🎯 重构目标

### 设计原则

1. **单一数据源** — Timeline.md 为真实任务管理文件，.home 只作视图配置
2. **渐进增强** — 从核心功能开始，逐步叠加高级特性
3. **视觉优先** — 仪表盘风格，信息可视化，减少文字堆砌
4. **操作就近** — 减少跳转，支持原地编辑/勾选/拖拽
5. **响应式设计** — 支持 1920px 大屏到 1280px 小屏

### 1. 数据模型重构

#### 1.1 项目元数据结构（.home 文件）

```typescript
interface ProjectConsoleData {

  name: string;
  icon: string;
  description: string;
  type: ProjectType;
  status: "active" | "paused" | "completed" | "archived"; // 新增
  createdAt: string;          // YYYY-MM-DD
  updatedAt?: string;         // 自动更新
  
  // ── 项目元数据（新增）──
  metadata: {
    priority: "low" | "medium" | "high" | "urgent";  // 优先级
    deadline?: string;                                // 截止日期
    tags: string[];                                   // 标签（如 #客户项目 #长期）
    collaborators: string[];                          // 协作者
    dependencies: string[];                           // 依赖的其他项目路径

    customSections: Array<{    // 自定义分组
      id: string;
      label: string;
      query: string;           // 文件筛选规则
    }>;
  };
  
  // ── 里程碑（新增）──
  milestones: Array<{
    id: string;
    title: string;
    deadline: string;
    completed: boolean;
    deliverables: string[];    // 关联的交付物路径

  // ── 任务（保留，但改为只读视图）──
  // 真实任务数据从 Timeline.md 解析
  tasks: ProjectConsoleTask[];        // 废弃，仅用于向后兼容
  
  // ── 交付物（保留）──
  deliverables: ProjectConsoleDeliverable[];
}
```

### 2. 功能模块重构

#### 2.1 主页 - 每日回顾模块

**目标**: 从「占位符」升级为「可操作仪表盘」

**数据来源**:
- **今日元气值** = 今日创建笔记数×20 + 完成任务数×15 + 编辑文件数×5 + 专注时长（分钟）×0.5
- **记录笔记** = 今日创建的 .md 文件数（排除模板、归档）
- **完成待办** = Timeline.md 中今日打勾的任务数
- **阅读文章** = 今日打开且停留 >3 分钟的文件数（需埋点）
- **剩余待办** = 所有项目 Timeline.md 中未完成任务数

**交互改进**:
- 点击「记录笔记」→ 展开今日创建的笔记列表（悬浮卡片）
- 点击「完成待办」→ 展开今日完成的任务列表
- 点击「剩余待办」→ 跳转到待办 Tab 并筛选「今天」

**UI 改进**:
- 环形进度条增加动画过渡
- 检查列表右侧图标状态化：✓ 已达成 / ○ 未达成 / ⚠️ 需关注

#### 2.2 主页 - 进行中的项目模块

**目标**: 从「简单列表」升级为「可筛选的项目工作台」

**新增功能**:
1. **状态筛选器**（顶部 Tab 栏）
   - 全部 / 进行中 / 暂停 / 本周截止
2. **排序选项**（下拉菜单）
   - 最近更新 / 优先级 / 完成度 / 截止时间
3. **快速操作**（项目卡片右上角悬浮）
   - ⭐ 置顶
   - ⏸️ 暂停/恢复
   - 📌 打开控制台
   - 📁 打开项目文件夹

**UI 改进**:
- 项目卡片增加紧急度标识（红点 = 即将截止，橙点 = 本周截止）
- 进度条下方显示「3/10 任务」而非只有百分比
- 鼠标悬停显示完整项目路径和标签

#### 2.3 主页 - 待办模块

**目标**: 从「只读列表」升级为「可操作的任务中心」

**新增功能**:
1. **原地勾选** — 点击任务左侧复选框 → 直接修改 Timeline.md 文件
2. **快速跳转** — 点击任务文本 → 跳转到对应项目 Timeline.md 并高亮该行
3. **任务详情气泡** — 悬停显示：所属项目、创建时间、截止时间、任务描述
4. **批量操作** — 按住 Ctrl 多选任务 → 批量标记完成/删除/移动

**数据来源改进**:
- 从所有项目的 `Timeline.md` 聚合任务
- 支持识别截止时间标记：`@due(2026-07-15)`
- 支持优先级标记：`@priority(high)`

**UI 改进**:
- 已完成任务置灰且折叠到底部（可展开）
- 截止时间用颜色标识：红色 = 已逾期，橙色 = 今天截止，绿色 = 未来
- Tab 计数显示未完成数量（如「今天 (5)」）

#### 2.4 主页 - 便签模块

**目标**: 从「简单书签」升级为「快速笔记入口」

**新增功能**:
1. **原地编辑** — 双击便签 → 在主页弹出编辑器（支持 Markdown 预览）
2. **分类标签** — 支持给便签打标签（工作/生活/灵感/待办）
3. **置顶功能** — 重要便签可置顶（显示在最前）
4. **颜色自定义** — 扩展到 5 种颜色（黄/蓝/绿/粉/紫）
5. **快捷创建** — 支持从选中文本快速创建便签

**UI 改进**:
- 便签卡片增加阴影和悬浮动画
- 显示创建时间（底部小字）
- 空状态改为「+ 创建第一个便签」按钮

#### 2.5 主页 - 热力图模块

**目标**: 从「单一维度」升级为「多维度活动可视化」

**新增功能**:
1. **活动类型筛选** — 顶部 Toggle：全部 / 笔记 / 任务 / 编辑
2. **悬停详情** — 鼠标悬停显示：当日创建 X 条笔记、完成 Y 个任务、编辑 Z 个文件
3. **点击钻取** — 点击日期格子 → 弹出当日活动明细（时间线）
4. **连续天数徽章** — 图例下方显示「🔥 连续活跃 7 天」

**数据来源改进**:
- 从 `HomepageData.activityLog` 读取每日统计
- 统计粒度：创建笔记数、编辑文件数、完成任务数、专注时长

**UI 改进**:
- 颜色层级更明显（0/1/2/3/4 五级深浅）
- 月份标签更清晰（加粗当前月）

#### 2.6 主页 - 本月数据模块

**目标**: 从「假数据」升级为「真实趋势分析」

**新增功能**:
1. **真实趋势图** — 基于 `activityLog` 生成近 30 天折线图
2. **点击钻取** — 点击卡片 → 展开详细数据表格
3. **环比增长** — 趋势标签显示「较上月 +23%」
4. **数据导出** — 支持导出为 CSV

**数据来源**:
- 从 `HomepageData.activityLog` 读取历史数据
- 自动计算月度汇总和环比

**UI 改进**:
- 折线图使用真实数据点（SVG path 动画）
- 卡片底部引言区域改为「本月总结」（如「本月创建了 23 条笔记，连续活跃 15 天」）

#### 2.7 项目控制台（.home 视图）

**目标**: 从「简单任务列表」升级为「项目工作台」

**新增功能**:
1. **里程碑时间线** — 新增「里程碑」Tab，展示关键节点和交付物
2. **项目统计面板** — 顶部增加统计卡片（总文件数、总工时、协作者、标签）
3. **快速操作栏** — 右上角添加：⚙️ 设置 / 🗂️ 归档 / 📤 导出报告
4. **任务同步** — 任务数据直接从 Timeline.md 读取（不再保存在 .home）
5. **交付物状态管理** — 支持拖拽调整交付物状态

**UI 改进**:
- 顶部 Hero 区域增加项目状态徽章（进行中/暂停/完成）
- 统计卡片使用图标 + 数字 + 趋势箭头
- 底部快捷操作网格改为 2×2 布局，增加「新建笔记」「新建任务」

### 视觉优化

1. **卡片分层**
   - 添加 `box-shadow: 0 2px 8px rgba(0,0,0,0.08)`
   - 悬停时提升：`box-shadow: 0 4px 16px rgba(0,0,0,0.12)`

2. **动画过渡**
   - 卡片进入：`fade-in-up` 0.3s 延迟错开
   - 数据更新：`count-up` 数字滚动动画
   - 进度条：`width` 过渡 0.5s ease-out

3. **空状态设计**
   - 图标 + 标题 + 描述 + CTA 按钮
   - 示例：「还没有项目？创建第一个项目开始管理」

4. **交互反馈**
   - 按钮点击：`scale(0.95)` 0.1s
   - 复选框勾选：✓ 符号弹跳动画
   - 卡片拖拽：半透明阴影
