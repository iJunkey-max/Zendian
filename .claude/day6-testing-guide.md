# Day 6 功能测试指南 - 便签编辑弹窗

## ✅ 已完成的功能

### 核心功能：便签编辑弹窗
- ✅ 双击便签卡片 → 弹出 Markdown 编辑器

#### 测试 3.1: 双击打开编辑器 ⭐ 核心功能

**操作**: 找到「便签」卡片，**双击**任意便签

**预期结果**:

2. 窗口分为两栏：

3. 标题栏显示：「编辑便签：[便签标签]」
4. 状态指示器显示「已保存」（灰色背景）
5. 编辑器自动聚焦，光标定位到末尾

#### 测试 3.2: 实时预览

**操作**: 在左侧编辑器中输入以下 Markdown 内容

```markdown

**预期结果**:
- 右侧预览区实时显示渲染后的内容
- 标题有对应的大小和样式
- 粗体/斜体/代码正确显示
- 列表有正确的缩进
- 代码块有背景色
- 引用有左侧边框
- 链接显示为蓝色

#### 测试 3.3: 自动保存

**操作**: 
1. 在编辑器中输入一些文字
2. 观察状态指示器的变化
3. 停止输入，等待 1 秒

**预期结果**:
1. **输入时**: 状态显示「未保存」（普通样式）
2. **输入后**: 状态变为「保存中...」（蓝色背景）
3. **1 秒后**: 状态变为「已保存」（绿色背景）
4. 关闭编辑器，双击便签重新打开
5. 确认修改已保存

#### 测试 3.4: 手动保存 (Ctrl+S)

**操作**:
1. 在编辑器中输入文字
2. 立即按 `Ctrl+S`（不等待 1 秒）

**预期结果**:
- 状态立即变为「已保存」
- 无需等待防抖时间

#### 测试 3.5: 键盘快捷键 (Esc)

**操作**: 
1. 在编辑器中输入一些文字
2. 等待自动保存（1 秒）
3. 按 `Esc` 键

**预期结果**:
- 编辑器窗口关闭
- 回到主页，便签内容已更新

#### 测试 3.6: 关闭时自动保存

**操作**:
1. 在编辑器中输入文字
2. 立即点击窗口外部（关闭窗口，不等待自动保存）

**预期结果**:
- 窗口关闭时触发最后一次保存
- 主页便签内容已更新

#### 测试 3.7: 与单击事件兼容性

**操作**: 
1. **单击**便签（不是双击）
2. 等待 200ms

**预期结果**:
- 单击时打开便签对应的文件（原有功能保留）
- 不会弹出编辑器

**操作**: **双击**便签

**预期结果**:
- 弹出编辑器，不打开文件

## 🎯 已知限制

1. **预览区暂不支持**:
   - Obsidian 双向链接 `[[文件名]]`（会显示为普通文本）
   - 嵌入内容 `![[图片]]`
   - Dataview 查询
   - 这些功能需要完整的 Obsidian 上下文，编辑器只提供基础 Markdown 预览

2. **单击延迟**: 单击便签会有 200ms 延迟（避免与双击冲突）

3. **窗口大小**: 固定为 90vw × 80vh，暂不支持调整大小
