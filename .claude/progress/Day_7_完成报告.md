### 2. 每日回顾真实数据

#### 数据源整合
- 集成 `ActivityLogService` 到主页视图
  - 在 `onOpen()` 中初始化和加载活动日志服务
  - 替换原有的模拟数据计算逻辑

#### 改进的统计逻辑
- **笔记统计**：使用 `todayActivity.created`（今日创建的笔记数）
- **待办统计**：优先使用 `TaskService` 的真实待办数据，失败时回退到活动日志
- **编辑统计**：使用 `todayActivity.edited`（今日编辑的文件数）
- **剩余待办**：动态计算，完成时显示鼓励语

#### 元气值算法优化
```
energyScore = 
  min(创建笔记 × 20, 40) +     // 最多 40 分
  min(完成待办 × 10, 30) +     // 最多 30 分
  min(编辑文件 × 2, 20) +      // 最多 20 分
  min(连续活跃天数 × 2, 10)    // 最多 10 分
```
总分上限 100 分，基于真实活动数据动态计算。

## 📊 技术实现

### 架构设计
```
HomepageView
  ├─ ProjectFilterBar（筛选器 UI）
  ├─ ProjectFilterUtils（筛选/排序逻辑）
  ├─ ActivityLogService（活动日志服务）
  └─ 状态管理
      ├─ currentProjectFilter（当前筛选条件）
      └─ allProjects（所有项目缓存）
```

### 数据流
```
用户选择筛选条件
  ↓
onFilterChange 回调
  ↓
更新 currentProjectFilter
  ↓
renderFilteredProjects()
  ↓
applyFilterAndSort(allProjects, filter)
  ↓
更新 UI（项目列表 + 计数）
```

### 性能优化
- ✅ 项目数据缓存（`allProjects`）
- ✅ 筛选/排序在内存中执行
- ✅ 仅在筛选条件变更时重新渲染
- ✅ 防抖处理（ActivityLogService 内置）
