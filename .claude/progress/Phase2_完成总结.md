## 🔄 数据流程

### 1. 数据加载
```typescript
// 并行加载数据
const [trend, heatmap, stats] = await Promise.all([
  this.services.statistics.getActivityTrend(this.projPath, 30),
  this.services.timeline.getActivityHeatmap(this.projPath, 365),
  this.services.statistics.getTaskStatistics(this.projPath),
]);
```

### 2. 数据转换
```typescript
// 准备折线图数据
const labels = trend.map((d) => {
  const date = new Date(d.date);
  return `${date.getMonth() + 1}/${date.getDate()}`;
});
const data = trend.map((d) => d.count);

// 准备热力图数据
const heatmapData = Array.from(heatmap.entries()).map(([date, value]) => ({
  date,
  value,
}));
```

### 3. 图表渲染
```typescript
// 创建折线图
new LineChart(chartContainer, {
  labels,
  datasets: [{ label: "活动次数", data, color: "#3b82f6" }],
}, { width: 800, height: 250 });

// 创建热力图
new HeatmapChart(chartContainer, heatmapData, {
  width: 800,
  height: 150,
  colorScale: ["#ebedf0", "#9be9a8", "#40c463", "#30a14e", "#216e39"],
});
```

## 💡 最佳实践

### 任务管理建议

1. **优先级使用**
   - P0：紧急任务，需要立即处理
   - P1：重要任务，高优先级
   - P2：普通任务，正常处理
   - P3：低优先级，可以延后

2. **标签使用**
   - 使用简短标签（如 "bug"、"feature"、"docs"）
   - 避免过多标签（建议 2-3 个）
   - 使用统一的标签命名规范

3. **截止日期使用**
   - 设置合理的截止日期
   - 避免过于紧迫的截止日期
   - 定期检查和更新截止日期

### 数据可视化建议

   - 热力图：展示活动分布

2. **性能优化**
