# ZENdian V4.0.02 发布说明

发布日期：2026-11-06

V4.0.02 修复设置面板与项目创建问题，并整理现有二级面板的工作区弹出窗口生命周期。最低支持版本仍为 Obsidian 1.12.7。

## 设置面板

- 调整下拉控件背景，避免箭头图像重复平铺；修改选项或恢复默认时保留搜索内容和滚动位置。
- 新增分类时检查文件夹冲突并防止重复提交；打开分类设置时，尝试为已配置且有效的分类补建缺失文件夹。

## 项目创建

- 将新项目暂存目录改为 Vault 可索引的位置，修复使用配置目录暂存时可能导致的创建失败。
- 创建失败时保留错误提示和暂存清理；项目扫描会忽略专用暂存目录，不把未发布项目识别为正式项目。

## 二级面板窗口

番茄钟、全部项目等现有面板继续使用 Obsidian 工作区弹出窗口，窗口创建失败时保留原有回退方式。窗口关闭、创建失败及插件卸载时会清理对应会话和视图，并发的独立表单按窗口区分会话。

这些面板没有复用 Obsidian 1.13 设置窗口的内部外壳；工作区弹出窗口与新版设置窗口的外观和行为可能不同。

## 升级与验证

- 升级前建议备份知识库。V4.0.00 的项目数据迁移背景和恢复说明见 [V4.0.00 发布说明](./RELEASE_NOTES_4.0.00.md)及[项目数据与恢复](../docs/项目数据与恢复.md)。
- `npm run check` 和 `npm run build` 已在工作副本通过；V4.0.02 已安装到测试仓库，安装文件与构建产物一致。
- 浅色/深色主题、移动端以及各弹出面板的实际交互尚需在 Obsidian 中手工验收。

完整版本历史见 [更新日志](../CHANGELOG.md)。
