# ZENdian V4.0.01Fix 发布说明

发布日期：2026-11-04  
最低 Obsidian 版本：1.12.7

V4.0.01Fix 继续保持同一版本号，包含 V4.0.00 界面统一后的主页与项目控制台回归修复，以及启用 ZENdian 后 Markdown 文件无法打开的重大启动修复。统一 token 层在收敛各处样式的同时，把主页原有的视觉层次和列表节奏一并抹平了，项目控制台的标签条在切换内容时也会被向上拉扯。本次版本恢复主页的分层页面场与扁平列表，锁定控制台的布局契约，修正项目简介的点击区域，并确保 Markdown 编辑器能够正常创建。

## 一、主页视觉回归修复

### 1. 恢复分层页面场

`css/ui/unified-ui.css` 重新引入主页的点阵背景与柔和渐变层次：

- 浅色模式使用低透明度的点阵与两处椭圆渐变，保持克制；
- 深色模式使用更高对比度的变体，避免背景在暗色下发灰；
- 浅色主题下 `--surface` 恢复纯白，卡片面与页面场形成明确的层次差。

其余界面继续使用统一 token，本次改动只作用于 `.zendian-homepage` 范围。

### 2. 列表行回归扁平样式

主页的项目行与待办行此前被统一卡片层包成了独立的嵌套卡片。本次恢复 V3.2 的处理：

- `background: transparent`、`border: 0`、`box-shadow: none`；
- 悬停仅改变背景色，不再叠加边框与阴影；
- 列表以分隔线建立节奏，不靠逐行卡片制造层级。

## 二、项目控制台布局与交互

### 1. 布局契约

新增控制台布局契约，保证身份块与标签条在正常文档流中，切换标签内容时标签条位置稳定：

- 标签条固定 52px 高度，`flex-basis` 与 `min-height` 同步，内容增减不会改变其占位；
- 标签项禁用位移变换，悬停、聚焦和按下状态都不会移动位置；
- 工作区内容层使用 `flex: 1 1 auto` 与 `min-height: 0`，滚动限制在内容区域内；
- 简介区改为默认指针与透明背景，点击简介正文不会误触发编辑；
- 最近活动列表行改用扁平样式，以分隔线建立节奏。

响应式断点下同步收紧面包屑、身份块与标签条的间距。

### 2. 移除冗余路径条

项目头部的「当前文件夹」路径条与面包屑重复表达同一信息，本次移除其标记与整套样式，页面只保留一处位置表达。

### 3. 简介编辑的点击区域

此前简介区整块都绑定点击进入编辑，导致误触频繁。本次改为：

- 「点击添加项目简介...」占位文字本身可点击，并补齐 `role="button"`、`tabindex="0"` 与 `aria-label`，支持 Enter 和空格键盘触发；
- 编辑按钮独立绑定事件，点击简介区域其他位置不再进入编辑；
- 摘要列表行移除 `zc-clickable` 样式，不再暗示整行可点击。

## 三、Markdown 编辑器启动修复

### 1. CodeMirror 运行时一致性

- 修复启用插件后 Markdown 文件无法打开的问题。
- 将 `@codemirror/state` 与 `@codemirror/view` 一并标记为 external，避免打字机扩展混用插件打包实例与 Obsidian 内置实例。此前两套 CodeMirror 运行时会使扩展对象被识别为非法值，并触发 `Unrecognized extension value in extension set`。

### 2. 打字机扩展安全初始化

- 打字机滚动使用的块级 spacer 改为按运行时资格动态注入。
- 普通 Markdown 编辑器初始化时不再预先挂载块级装饰，避免扩展启动阶段干扰 Markdown 视图创建；满足资格后仍可正常启用打字机滚动效果。

### 3. 验证结果

- 已完成 TypeScript 检查、项目契约检查与生产构建。
- 已在 Obsidian 测试库中重新加载 `V4.0.01Fix` 插件并打开 Markdown 文件，未再出现编辑器扩展错误或文件无法打开的问题。

## 四、升级与兼容说明

1. **本次发布基于 V4.0.00 代码线**，不包含 4.0.01 的共享面板骨架与项目主页重构。从 4.0.01 升级会回到 V4.0.00 的界面结构，并在此基础上获得本次修复。
2. 本次升级不修改 `.home` 文件结构、项目数据和设置格式，V4.0.00 的注册表、历史索引与检查点可直接沿用。
3. 自定义 CSS 片段若依赖「当前文件夹」路径条或项目行的卡片样式，升级后需要相应调整。
4. 仍建议升级前备份整个 Obsidian Vault，尤其是 `.home`、项目文件和 `.obsidian/plugins/zendian/data.json`。
5. 更新后重新加载 Obsidian 或重新启用 ZENdian 即可生效。

## 五、安装文件与验证

从 GitHub Releases 下载以下三个文件，放入 `.obsidian/plugins/zendian/` 目录并重新加载 Obsidian：

```text
main.js
manifest.json
styles.css
```
