# 项目管理重构实施记录（已纳入 V4.0.00）

本说明保留重构过程中的实施记录。完整功能已在 V4.0.00 发布；面向用户的变更摘要见 [V4.0.00 发布说明](./RELEASE_NOTES_4.0.00.md)，可复核证据见 [项目管理重构验收清单](../docs/项目管理重构验收清单.md)。

项目使用稳定身份识别，分类和显示名称可以独立于目录调整。新建支持可选编号、未分类和自定义父目录；现有目录可以登记为项目。重复身份、多个主页及嵌套项目会报告冲突。扫描只读，旧数据首次显式写入前备份，原 Markdown 保留。

任务支持编辑、撤销删除及项目内文件关联，使用最新主页增量写入并拒绝检测到的外部冲突。任务、阶段、里程碑、交付及恢复记录采用共享业务事件格式；检查点事件随历史索引保存。恢复工作内容时保留项目身份和已有操作历史。

交付发布默认可使用项目内“交付物”，无需先配置分类。源文件读取期间检测到变化时停止发布。包生成后主页保存失败会保留 ZIP 并报告路径，可在交付页使用“补登记已有发布包”；新包按项目 ID 核对归属，旧包按路径保守校验。

迁移包包含项目文件和可选快照历史，导入到新目录，支持独立身份。历史与位置索引发现外部修改时拒绝覆盖；索引损坏或历史写入失败时停止相关操作。以上比较不是跨设备事务或自动合并。

首页按实际容器宽度响应，修复左栏展开时每日回顾文字重叠；首页和控制台 Markdown 渲染传入所属视图组件。

当前证据及剩余验收以 [重构验收清单](../docs/项目管理重构验收清单.md) 为准。完整导出导入、检查点恢复、交付与补登记、浅色和移动端、多设备同步仍需对应实机证据。快照不是完整文件备份，使用前请阅读 [数据与恢复说明](../docs/项目管理数据与恢复说明.md)。
