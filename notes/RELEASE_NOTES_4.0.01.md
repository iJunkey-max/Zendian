# ZENdian V4.0.01 发布说明

发布日期：2026-11-04  
最低 Obsidian 版本：1.12.7

V4.0.01 在 V4.0.00 的项目模型重构之后，把界面层收敛到同一套结构与视觉规则。它没有引入新的业务能力，而是解决“每个面板各画一套相似界面”的分叉问题：新增共享面板骨架，重做项目主页的信息结构，并在构建末端补上统一的视觉校准层。主页仍是 ZENdian 的唯一视觉基准，其余界面都是它的延伸。

## 一、共享面板骨架

### 1. 三组面板原语

新增 `src/ui/panel-shell.ts`，提供三种可组合的外壳：

- `createSharedPanelShell`：面板标题栏与内容面，用于项目详情、项目列表和独立面板；
- `createSharedContentShell`：眉题、标题行、元信息与正文区，用于文档式内容面；
- `createSharedFormShell`：表单标题、说明、字段区和底部操作条，用于编辑与新建弹窗。

外壳只负责结构与语义，不接管数据专用样式。各调用方保留自身类名继续处理业务视觉，因此迁移不需要重写现有样式表。

### 2. 界面迁移到统一骨架

项目详情、项目列表、设置分组、项目检查与登记、导入迁移包、任务编辑、简介编辑、检查点和交付物弹窗均已改用共享外壳。快捷笔记、任务排期选择器、活动热力图和设置页控件同样收敛到共享结构。

迁移到的界面共享相同的标题层级、操作区位置、内容边距、空状态表达和焦点行为；此前各处复制的标题栏、内容面和表单底栏结构已被移除，后续新增面板不必再复制一套相似 CSS。

## 二、项目主页重构

### 1. 项目主页是工作文档，不是仪表盘

新增 `css/overlays/project-home-redesign.css`。首屏只回答三个问题：

1. 这是什么项目，当前处于什么阶段？
2. 项目目标是什么？
3. 下一步最应该推进哪一个具体动作？

完整的任务、交付物、动态、数据和文件列表进入各自的工作区标签，不在概览页重复堆叠。

### 2. 主文档面 + 窄侧栏

概览、任务、交付物、动态、数据、文件六个标签共用同一套页面骨架：

- 主文档面承载项目目标、当前推进和下一步行动；
- 窄侧栏收纳项目节奏、阶段进度、任务/交付物/文件摘要与近期活动。

侧栏内容按需收起，窄窗口和移动端改为自然滚动，不做固定高度裁切。

### 3. 移除的装饰

按设计规范取消了以下做法：

- 霓虹色、装饰渐变、发光边框和卡片顶部装饰条；
- 无业务意义的编号；
- 同一指标的重复统计卡。

列表以分隔线建立节奏，不再把每一行内容包成独立卡片。圆角只用于内容面和控件。主要按钮只保留一个强调层级，编辑、导出、切换和删除保持低强调。空状态必须给出下一步动作。

## 三、视觉校准与统一

### 1. 构建末端的校准层

新增 `css/ui/polish-ui.css`（主页、面板与控件的最终视觉校准层）和 `css/overlays/project-home-redesign.css`（项目主页与二级面板的最终重构层），两者在 `scripts/build-css.mjs` 合并顺序末端叠加于 `css/ui/unified-ui.css` 之上，保证 V4.0.00 引入的统一 token 层不被局部样式覆盖。

`css/design-system.css` 补充共享 token，`css/overlays/homepage.css` 收敛主页残留的硬编码选择器。

### 2. 颜色与排版规则

- 强调色只用于当前状态、主要动作、进度、图标和焦点，不用于大面积装饰、发光效果和渐变标题线。
- 便签沿用主页语义：黄色提醒、蓝色想法、绿色进展。便签不是状态按钮，不作为唯一的状态表达。
- 字体使用 Obsidian `--font-interface`，不为 ZENdian 单独加载字体；标题不使用全大写和装饰性字距。
- 颜色优先引用 `css/design-system.css`、`css/ui/unified-ui.css` 和主页已有变量，新面板不新增孤立颜色，也不硬编码主题色。
- 浅色、深色、窄窗口、平板和手机沿用同一套变量自然降级。

## 四、设计规范与验收证据

新增两份规范文档：

- [前端 UI 设计规范](../docs/ui-design-spec.md)：颜色 token、字体层级、间距/圆角/阴影、控件高度、状态色与组件复用规则。
- [项目主页设计规范](../docs/project-home-design-spec.md)：页面骨架、信息顺序、视觉规则，以及相对 Linear、Todoist、Basecamp 的参考取舍。

新增 `docs/ui-preview/` 共 22 张实机核对图与整体结构图，覆盖主页、项目主页、任务、交付物、动态、文件、数据、修复、设置、控制台以及深色模式。

## 五、升级与兼容说明

1. 本次升级**不修改 `.home` 文件结构、项目数据和设置格式**，V4.0.00 的注册表、历史索引与检查点可直接沿用。
2. 界面结构有明显变化：项目主页的首屏布局、二级面板的标题栏和设置页控件均改为共享骨架。自定义 CSS 片段若依赖旧的面板 DOM 层级，升级后可能需要调整。
3. 仍建议升级前备份整个 Obsidian Vault，尤其是 `.home`、项目文件和 `.obsidian/plugins/zendian/data.json`。
4. 更新后重新加载 Obsidian 或重新启用 ZENdian 即可生效。

## 六、安装文件与验证

从 GitHub Releases 下载以下三个文件，放入 `.obsidian/plugins/zendian/` 目录并重新加载 Obsidian：

```text
main.js
manifest.json
styles.css
```

- `npm run build` 生产构建；
