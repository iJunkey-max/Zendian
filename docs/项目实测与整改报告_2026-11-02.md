# ZENdian 项目实测与整改报告

## 范围和环境

- 本地源码版本：3.2.05；Obsidian 1.12.7，Windows，桌面浅色界面。
- 使用仓库生成器创建独立测试库 `.codex-test-vault`，加载本次构建的插件。原有知识库未用于测试写入。
- 覆盖：首页、创建项目、项目列表、项目任务、时间轴、专注时钟启动。未覆盖移动端、深色、同步冲突、交付物和检查点恢复。
- `npm run check` 通过；JS 构建在正常文件系统权限下通过。受限环境中的首次构建因上级目录访问被拒绝而失败。

## 已复现问题

### P0：项目控制台无法通过弹出窗口添加任务

1. 首页新建项目，打开项目控制台。
2. 点击“添加任务”。
3. 弹出窗口显示“缺少项目路径，无法添加任务”，表单不可用。

首页“新建待办”选择该项目可以成功创建任务，说明项目本身和任务写入可工作。代码中打开弹窗时传入 `state.projectPath`，而弹窗 `onOpen` 从 `leaf.getViewState().state` 读取，可能存在视图状态应用时序问题，需进一步验证而非直接认定根因。涉及 `src/homepage/ProjectConsoleView.ts` 的 `ProjectTaskCreatePopoutView.onOpen` 和 `openAddTaskWindow`。

### P1：每日回顾把历史完成任务当作今日完成量

测试首页“每日回顾”显示完成 72 项待办，而本月完成任务显示 0；代码实际统计所有项目里当前已完成的任务总数，并用于“今日元气值”的任务得分，而非当天完成数。历史任务会持续影响每日数据和分数。见 `src/homepage/HomepageView.ts` 的 `loadDailyReviewStats`。

### P1：每日回顾的指标名称与实际数据不同

界面左侧写“阅读文章”，右侧显示“编辑了 N 个文件”，代码使用 `todayActivity.edited`。应统一指标定义、文案和计数口径。

### P1：任务“本周”筛选在周日跨到下一周

`TaskSyncService.filterWeekDue` 用 `7 - getDay()` 算结束日；周日 `getDay()` 为 0，结束日变为下周日。需先明确一周起止规则，再修复并测试周日和跨年边界。

### P2：项目文件计数口径不一致

新建项目只有系统生成的 `项目主页.home`，项目预览显示 0 个文件，控制台侧栏显示 1 个文件。应统一是否将系统文件计入，并在统计处说明。

### P2：项目控制台侧栏在当前桌面窗口下出现文字挤压

控制台“健康度”“优秀”等文字在窄侧栏中被拆行，数值阅读困难。需检查自适应断点、最小列宽和不同窗口尺寸；不能据此推断移动端表现。

### P2：专注目标默认使用内部文件名

在“流程核验项目”控制台打开专注时钟，目标预填“项目主页”，而非项目显示名。代码使用当前文件 `basename`。功能本身可以启动，但目标名称缺少项目辨识度；项目关联与时长归集仍需专项验证。

### P2：时间轴中系统文件更新产生较多技术性事件

一次创建、切换和完成任务后，时间轴同时出现多条“编辑文件：项目主页.home”，与任务业务事件混排。这些记录有技术用途，但可能淹没用户真正关心的项目活动。可考虑默认弱化系统文件事件并保留筛选入口。

## 已验证可用的路径

- 创建“流程核验项目”后，项目目录及 `.home` 数据文件成功生成，全部项目列表能显示该项目。
- 从首页创建任务并指定该项目，任务成功写入 `.home`；项目控制台显示该任务。
- 在控制台勾选任务后，`.home` 的 `completed` 和 `completedAt` 更新；时间轴显示任务完成事件。
- 专注时钟可打开并开始倒计时；测试计时已暂停。尚未验证完整结束、记录写入及复盘统计。

## 产品与视觉建议

1. 首先修复项目内任务创建、今日统计和周筛选，建立针对这些行为的回归测试。
2. 明确 `.home`、普通 Markdown 待办、项目状态、任务完成率、项目完成度和活动记录的关系；修正设置页仍称 Timeline 为事实源的过期说明。
3. 梳理新手主线：创建项目 → 添加任务 → 首页执行 → 复盘；提供明确空状态和下一步。
4. 审视首页、项目控制台、设置、弹窗及专注窗口的按钮、卡片、排版和反馈；抽出共享组件和设计变量，在浅色、深色、窄窗口与移动端逐项验证。
5. 将迁移、检查点恢复、并发写入和外部同步作为独立数据安全专项，使用复制数据验证失败与恢复路径。

## 说明

项目预览显示 0 文件、控制台显示 1 文件，以及“健康度”挤压均为当前环境观察结果。测试库由脚本生成，包含旧版 Timeline 数据，部分历史活动为模拟数据；不要将其数值当作真实用户数据。测试中未更改源码，测试库是工作区内未跟踪目录。
