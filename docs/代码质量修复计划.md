# ZENdian 代码质量修复计划

## 目标

消除审查中发现的数据丢失、持久化失效、并发覆盖、远程 SVG 注入、快照队列失效、日期偏差和高频扫描问题，并建立可重复执行的安全回归检查。

## 修复阶段

1. 数据安全与持久化
   - 使用 `Vault.configDir` 和 Adapter API 存储插件私有数据。
   - 活动监听延迟到 workspace layout ready。
   - 用户文件删除与旧项目迁移改用 Vault 回收站。
   - 损坏 JSON 在回退前创建备份。

2. 并发与生命周期
   - `.home` 修改按项目串行，并在写入临界区重读最新数据。
   - 快照和活动日志写队列可从单次失败中恢复。
   - 设置卸载时强制 flush 待保存数据。

3. 输入与供应链安全
   - 第三方 SVG 使用元素和属性白名单净化。
   - ZIP 在解压前检查声明大小、条目数和边界，解压过程中限制实际输出。

4. 正确性与性能
   - 用户可见日期统一使用本地日历日期。
   - Vault 事件只对项目目录触发刷新，按项目失效缓存并防抖、去重并发刷新。
   - 图表 tooltip 使用 DOM 文本节点，不拼接动态 HTML。

5. 工程保障
   - 增加 `.gitignore`。
   - 增加 `check:safety` 与统一 `check` 命令。
   - 通过 TypeScript、设置契约、安全契约和生产构建验证。

## 验收命令

```bash
npm run check
npm run build
```
