# ZENdian 前端 UI 设计规范

版本：2026-11-04  
适用范围：主页、主页二级面板、项目控制台、设置页、设置新窗口、表单弹窗、专注时钟及所有 ZENdian 自有控件。

## 1. 设计基准

上一版主页是 ZENdian 的视觉基准，不另起一套“仪表盘”或“概念工作台”风格。所有新面板都必须能够被理解为上一版主页的延伸：

- 使用浅色主题中的柔和灰白背景、白色内容面和低对比度边框；暗色主题使用 Obsidian 变量自动映射，不硬编码一套独立黑色主题。
- 保留主页的点阵背景、12 列信息布局、搜索胶囊、天气卡、圆角卡片和黄/蓝/绿便签。
- 强调色只用于当前状态、主要动作、进度、图标和焦点，不用于大面积装饰、发光、渐变标题线或卡片顶部装饰条。
- 内容优先于装饰。标题说明“这里是什么”，按钮说明“点击会做什么”，空状态说明“下一步怎么做”。
- 面板之间复用结构和控件，不通过复制一套相似 CSS 制造分叉。

## 2. 视觉 Token

### 2.1 颜色

颜色应优先引用 `css/design-system.css`、`css/ui/unified-ui.css` 和主页已有变量。禁止在新面板中新增孤立颜色。

| 语义 | Token | 用途 |
| --- | --- | --- |
| 主题强调色 | `--zd-primary` / `--interactive-accent` | 当前标签、主要按钮、进度、焦点 |
| 页面背景 | `--zd-ui-page` / `.zendian-homepage --bg` | 面板外层、页面滚动区域 |
| 内容面 | `--zd-ui-control` / `.zendian-homepage --surface` | 卡片、设置分组、列表项 |
| 柔和内容面 | `--zd-ui-surface-soft` | 空状态、筛选工具栏、次级摘要 |
| 正文 | `--zd-ui-text` / `--text-normal` | 标题、主要信息 |
| 次要文字 | `--zd-ui-text-muted` / `--text-muted` | 描述、时间、路径 |
| 弱化文字 | `--zd-ui-text-faint` / `--text-faint` | 占位符、提示、不可用状态 |
| 分割线 | `--zd-ui-divider` | 卡片边框、标题栏底线、列表分隔 |
| 成功 | `--zd-success` | 完成、已登记、有效状态 |
| 警告 | `--zd-warning` | 逾期、暂停、需要检查 |
| 错误 | `--zd-error` | 读取失败、冲突、危险操作 |

便签颜色沿用主页：黄色表示提醒，蓝色表示想法/灵感，绿色表示进展/完成。便签不是状态按钮，不能用作唯一的状态表达。

### 2.2 字体

- 界面字体使用 Obsidian 的 `--font-interface`，不为 ZENdian 单独加载字体。
- 页面标题：20–24px，`600–700`，不使用全大写，不使用装饰性字距。
- 面板标题：17–20px，`600`。
- 卡片标题：14–16px，`600`。
- 正文：13–14px，行高 1.5。
- 辅助信息：11–12px，使用次要或弱化文字颜色。
- 数字统计可以加粗，但必须紧邻语义标签，不单独制造“英雄数字”版式。

### 2.3 间距、圆角、阴影

以 4px 为基础单位，引用 `--zd-space-*`：

- 页面内边距：24px；窄屏降为 14–16px。
- 卡片之间：16–20px；列表项之间：8–12px。
- 卡片内边距：16–24px，按内容密度调整。
- 卡片圆角：`--zd-ui-radius-card`，默认 12px。
- 控件圆角：`--zd-ui-radius-control`，默认 8px。
- 搜索框和筛选胶囊使用 `9999px`，只用于明显的胶囊控件。
- 默认只使用 `--zd-ui-shadow-card`；悬停使用 `--zd-ui-shadow-hover`。不使用强烈发光或多层玻璃阴影。

## 3. 面板框架

### 3.1 标准面板壳

详情、全部项目、全部待办、全部便签、独立表单窗口都使用同一层级：

```text
zd-panel-shell / 具体业务类
├─ zd-panel-header + 业务兼容类
│  ├─ zd-panel-icon
│  ├─ zd-panel-header-info
│  │  ├─ zd-panel-title
│  │  └─ zd-panel-meta（可选）
│  └─ zd-panel-close
└─ zd-panel-body
   └─ 内容区 / 列表 / 统计 / 空状态
```

公共结构由 `src/ui/panel-shell.ts` 创建：`createSharedPanelShell()` 负责标准标题栏/关闭按钮，`createSharedContentShell()` 负责控制台 tab 的标题和内容区，`createSharedFormShell()` 负责表单标题、说明、输入区和底部操作区。三个 helper 本身不携带 `hp-*` 或 `zc-*` 业务类名；兼容类只在调用点显式映射，避免公共 API 被主页或控制台反向绑死。业务面板可以保留这些类名承载内容样式，但不能重复实现标题栏和关闭按钮。

### 3.2 主页卡片

主页卡片使用 `.homepage-card`：

- 标题栏左侧：图标 + 标题。
- 标题栏右侧：最多 2 个动作，优先使用图标按钮或“全部”。
- 内容区域：列表、统计、图表或便签。
- 列表区域可滚动，但卡片标题和主要动作保持可见。
- 同一行的卡片高度应尽量一致，避免因为一处文案撑高整行。

### 3.3 表单窗口

新建项目、新建待办、快速便签及可复用的表单 Popout 使用 `zd-form-shell`：

- `zd-form-header` 只放标题和一句说明，不把业务编号或装饰性标签塞进标题。
- `zd-form-body` 承载 Obsidian 原生 `Setting`，保持控件行为和键盘操作不变。
- `zd-form-actions` 统一放取消与主要动作，取消在左、确认在右，同组只保留一个强调按钮。
- 内嵌 Modal 与独立新窗口只改变宿主容器，内容、按钮和表单结构保持一致。

### 3.4 设置分组卡

设置页使用 `.zendian-section-card`：

- 分组标题、上下文说明、恢复本组按钮位于同一标题栏。
- 单项设置使用 Obsidian `Setting`，不自行发明第二套标签/开关。
- 高级设置使用 `<details class="zendian-advanced">`，默认收起。
- 设置搜索结果仍复用相同 section card，不创建搜索专用卡片。

### 3.5 项目控制台工作区

项目控制台保留“主内容 + 右侧摘要”的信息架构：

- 顶部：面包屑、项目名称、项目状态、简介和导出/编辑动作。
- 主内容：通过标签切换概览、任务、交付物、动态、数据、文件。
- 右侧：任务完成率、项目状态、交付物数、文件数、近期活动。
- 具体 tab 内容统一使用控制台内部的 `createPanelShell`，不再为每个 tab 重新设计标题结构。

## 4. 控件规范

### 4.1 按钮

按钮文字使用动作动词，保持全项目一致：

| 类型 | 样式 | 示例 |
| --- | --- | --- |
| 主要动作 | `mod-cta` / 强调色 | 新建项目、保存任务、确认导入 |
| 次要动作 | 默认按钮 / 边框 | 编辑项目、重新扫描、筛选 |
| 图标动作 | `.homepage-card-icon-btn` | 添加、查看全部、关闭 |
| 危险动作 | Obsidian danger 语义 | 删除、移除、确认危险操作 |
| 恢复动作 | 次要按钮 | 恢复本组、全部恢复默认 |

- 同一组操作最多一个主要动作。
- 破坏性动作不能与主要动作使用相同的视觉权重。
- 取消按钮放左，确认/保存按钮放右；窗口底部动作顺序固定。
- 图标按钮必须有 `title` 和 `aria-label`。

### 4.2 输入框、选择器、开关

- 普通输入高度使用 `--zd-ui-control-height`，默认 34px。
- 输入框、下拉框和文本域使用页面背景、统一边框和 8px 圆角。
- 聚焦时只显示一圈强调色 focus ring，不通过发光或位移制造反馈。
- 任务优先级、项目状态、项目分类使用文字 + 色彩；不能只依赖颜色。
- 开关使用 Obsidian 原生 `ToggleComponent`，只统一尺寸和强调色。

### 4.3 图标

- 优先使用 Obsidian/Lucide 图标。
- 面板图标 20–24px，卡片图标 14–16px，关闭图标 16px。
- 图标表达动作或类别，不用图标代替必要的文字。
- 不新增装饰性 SVG 插画，不使用带渐变、发光、复杂几何的 AI 风格图标。

## 5. 各面板信息和按钮

### 5.1 主页

展示：问候语、日期/引言、搜索、天气、每日回顾、项目、待办、便签、书签、热力图、月度统计、最近笔记。  
按钮：搜索、项目“全部/新建”、待办“添加/全部”、便签“添加/全部/上一条/下一条”、卡片内部的打开和完成操作。

### 5.2 全部项目

展示：项目总数、推进中数量、平均完成度、剩余待办；按项目分类分组，卡片展示图标、名称、路径、项目状态、任务完成度和进度。  
按钮：关闭、搜索、筛选/排序、点击卡片进入详情、空状态中的“新建项目”。

### 5.3 项目详情

展示：项目名称、分类、状态、任务完成数、进度、简介、统计卡片、待完成任务、最近编辑文件。  
按钮：关闭、打开项目、检查项目位置与身份、点击任务/文件进入对应内容。

### 5.4 全部待办

展示：当前筛选、任务总数、任务内容、完成状态、截止日期/时间、优先级、关联项目。  
按钮：关闭、切换全部/今天/本周/已完成、完成任务、编辑任务、删除任务、添加任务。

### 5.5 全部灵感速记

展示：速记数量、标签、Markdown 内容预览、来源路径和更新时间。  
按钮：关闭、新建速记、编辑速记、删除速记、上一条/下一条（主页轮播）。

### 5.6 项目控制台

展示：项目身份、状态、简介、任务完成率、交付物、文件数、近期活动和当前 tab 内容。  
按钮：编辑项目属性、编辑简介、新建任务、导出报告、导出迁移包、切换六个工作区 tab、交付物和快照相关操作。

### 5.7 设置页与设置新窗口

展示：设置分类、设置搜索、分组标题、说明、当前值、高级设置、关于信息和支持入口。  
按钮：搜索、新窗口、全部恢复默认、恢复本组、设置项自身的切换/选择/保存按钮。新窗口和原设置页使用同一 `ZENdianSettingTab.displayIn()` 渲染，不维护两份 UI。

### 5.8 表单和维护面板

适用：新建项目、编辑项目、编辑任务、导入项目、项目检查、快速便签、交付物操作、快照操作。  
共同结构：标题 → 一句说明 → 分组输入 → 结果/预览 → 底部动作。  
共同按钮：取消、保存/确认；耗时操作显示“处理中…”并禁用重复提交；失败时保留用户输入。

### 5.9 专注时钟

展示：当前项目、专注状态、剩余时间、已完成番茄数和本次记录。  
按钮：开始/暂停、继续、重置、选择项目、打开项目、关闭窗口。窗口样式使用普通内容面和主题色环形进度，不使用独立的霓虹主题。

## 6. 状态规范

每个异步面板至少定义四种状态：

1. 加载中：短文案 + 轻量占位，不使用全屏旋转动画。
2. 有数据：优先展示用户最常用的信息和主动作。
3. 空状态：说明为什么为空，并提供下一步动作，例如“暂无项目 / 新建项目”。
4. 加载失败：说明失败对象和可执行修复，例如“无法读取项目数据 / 重新扫描”。

状态文字不使用模糊的“出错了”“暂无内容”，也不在错误信息中隐藏操作入口。

## 7. 响应式与可访问性

- 主页和设置页基于实际容器宽度收缩，不只依赖 viewport 宽度。
- 720px 以下：卡片单列，标题栏动作保留可触控尺寸，输入框字号不小于 16px。
- 触控目标最小 40px；关闭、添加、完成和分页按钮必须可键盘聚焦。
- 弹窗打开后将焦点放在关闭或主要输入控件；关闭后回到触发按钮。
- 使用 `aria-label`、`aria-current`、`aria-selected`、`role="tab"` 表达状态。
- 遵守 `prefers-reduced-motion`，降低面板淡入、悬停位移和图表动画。

## 8. 实现边界和验收

- JS/TS 负责结构、数据、状态和 per-element CSS 变量；CSS 负责颜色、间距、布局和状态表现。
- 不猜测 Obsidian DOM；针对 Obsidian 原生设置项使用稳定的插件自有容器类和变量。
- 不重复实现相同面板标题栏；使用 `src/ui/panel-shell.ts` 的 `createSharedPanelShell()`。
- 新增面板前先决定它属于主页卡片、标准面板壳、设置分组、控制台工作区或表单弹窗中的哪一类。
- 完成一个面板后至少运行：`npm run build`、`npm run typecheck`、`npm run check:css`、`git diff --check`。
- UI 调整必须同时检查浅色主题、暗色主题、窄窗口、空状态、加载失败和键盘 focus。
