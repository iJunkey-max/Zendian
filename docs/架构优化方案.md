## 📦 核心服务详解

### 1. CacheManager（缓存管理器）

**功能：**
- 内存缓存（带 TTL 机制）
- LRU 淘汰策略（最近最少使用）
- 统计信息（命中率、缓存大小）

**使用示例：**
```typescript
import { CacheManager } from "./services";

const cache = new CacheManager(100, 5 * 60 * 1000); // 最多100条，TTL 5分钟

cache.set("key", data);
const result = cache.get("key");
cache.invalidate("key");
cache.invalidatePattern("project:*");
```

---

### 2. ProjectDataService（项目数据服务）

**功能：**
- 统一的项目数据读写接口
- 自动缓存和失效机制
- 数据验证和规范化
- 项目健康度评分

**API：**
```typescript
import { getServiceManager } from "./services";

const services = getServiceManager(app);

// 获取项目控制台数据
const data = await services.projectData.getProjectConsoleData(projectPath);

// 获取项目统计
const stats = await services.projectData.getProjectStatistics(projectPath);

// 获取项目健康度
const health = await services.projectData.getProjectHealth(projectPath);

// 获取最近文件
const recentFiles = services.projectData.getRecentFiles(projectPath, 10);

// 任务管理
const tasks = await services.projectData.getTasks(projectPath);
await services.projectData.addTask(projectPath, { text: "新任务" });
await services.projectData.updateTask(projectPath, 0, { completed: true });
await services.projectData.deleteTask(projectPath, 0);
```

**项目健康度评分：**
- 任务完成率 (40%)
- 文件活跃度 (30%)
- 更新频率 (20%)
- 最后活动时间 (10%)

**状态等级：**
- 80+：优秀（Excellent）
- 60-79：良好（Good）
- 40-59：一般（Fair）
- 0-39：需改进（Poor）

---

### 3. TimelineService（时间轴服务）

**功能：**
- 提取项目历史事件
- 文件创建/修改记录
- 任务创建/完成记录
- 交付物添加记录
- 活动热力图数据

**API：**
```typescript
// 获取完整时间轴
const timeline = await services.timeline.getProjectTimeline(projectPath);

// 获取最近事件
const recentEvents = await services.timeline.getRecentEvents(projectPath, 20);

// 获取日期范围内的事件
const events = await services.timeline.getEventsByDateRange(
  projectPath,
  new Date("2024-01-01"),
  new Date("2024-12-31")
);

// 获取按日期分组的事件
const grouped = await services.timeline.getEventsByDate(projectPath);

// 获取活动热力图（最近365天）
const heatmap = await services.timeline.getActivityHeatmap(projectPath, 365);
```

**事件类型：**
- `file-created`：文件创建
- `file-modified`：文件修改
- `task-created`：任务创建
- `task-completed`：任务完成
- `deliverable-added`：交付物添加

---

### 4. StatisticsService（统计分析服务）

**功能：**
- 任务统计分析
- 交付物统计
- 活动趋势分析
- 文件类型分布
- 周报/月报生成

**API：**
```typescript
// 任务统计
const taskStats = await services.statistics.getTaskStatistics(projectPath);
console.log(taskStats.completionRate); // 完成率
console.log(taskStats.overdue);        // 逾期任务数

// 交付物统计
const deliverableStats = await services.statistics.getDeliverableStatistics(projectPath);

// 活动趋势（最近30天）
const trend = await services.statistics.getActivityTrend(projectPath, 30);

// 文件类型分布（用于饼图）
const distribution = await services.statistics.getFileTypeDistribution(projectPath);

// 周报
const weeklyReport = await services.statistics.getWeeklyReport(projectPath);

// 月报
const monthlyReport = await services.statistics.getMonthlyReport(projectPath);
```

---

### 5. FileWatcher（文件监听服务）

**功能：**
- 监听项目文件变更
- 防抖处理（避免频繁触发）
- 自动失效相关缓存
- 发送变更事件

**API：**
```typescript
// 开始监听项目
services.fileWatcher.watchProject(projectPath, (event) => {
  console.log("文件变更:", event);
  // event.type: "project" | "task" | "deliverable" | "file" | "timeline"
  // event.action: "create" | "update" | "delete"
  // event.path: 变更的文件路径
});

// 停止监听
services.fileWatcher.unwatchProject(projectPath);

// 停止所有监听
services.fileWatcher.unwatchAll();
```

---

### 6. ServiceManager（服务管理器）

**功能：**
- 统一管理所有服务
- 协调服务之间的交互
- 提供便捷的 API
- 生命周期管理

**API：**
```typescript
import { getServiceManager, destroyServiceManager } from "./services";

// 获取服务管理器（单例）
const services = getServiceManager(app);

// 初始化服务
await services.initialize();

// 快捷方法：一次性获取项目所有数据
const fullData = await services.getProjectFullData(projectPath);

// 快捷方法：获取仪表盘数据
const dashboardData = await services.getProjectDashboardData(projectPath);

// 快捷方法：获取分析数据
const analytics = await services.getProjectAnalytics(projectPath);

// 清除缓存
services.clearProjectCache(projectPath);
services.clearAllCache();

// 销毁服务管理器
destroyServiceManager();
```

## 📈 性能优化

### 缓存策略
- **内存缓存**：避免重复读取文件
- **TTL 机制**：5 分钟自动过期
- **LRU 淘汰**：最多缓存 100 条数据
- **智能失效**：文件变更时自动失效相关缓存

### 数据加载优化
- **并行加载**：统计和健康度数据并行加载
- **按需加载**：时间轴数据异步加载
- **防抖处理**：文件监听防抖 200ms

## 📝 开发指南

### 添加新服务
1. 在 `src/homepage/services/` 创建新服务
2. 在 `types.ts` 添加类型定义
3. 在 `ServiceManager.ts` 集成新服务
4. 在 `index.ts` 导出新服务

### 使用服务
```typescript
import { getServiceManager } from "./services";

// 在视图中使用
class MyView extends ItemView {
  private services: ServiceManager;

  async onOpen() {
    this.services = getServiceManager(this.app);
    await this.services.initialize();
  }

  async loadData() {
    const data = await this.services.projectData.getProjectConsoleData(path);
  }
}
```

### 缓存策略
```typescript
// 手动清除缓存
services.clearProjectCache(projectPath);

// 监听文件变更自动失效
services.fileWatcher.watchProject(projectPath, (event) => {
  // 缓存会自动失效，无需手动处理
});
```
