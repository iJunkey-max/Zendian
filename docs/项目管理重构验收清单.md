## 尚需完成及验证

文件索引结构保护：项目字典、文件大小/时间/指纹及变化记录结构加载时校验；可解析 JSON 但条目损坏时停止扫描与写入，不自动替换基线。测试覆盖负文件大小及数组冒充项目字典，确认零写入；全量检查通过。

旧历史跨环境导入补验：FNV 内容通过导入服务迁入新路径后，原指纹保留、版本 ID重映射且检查点仍引用正确版本。当前完整源码全量检查和 JS/CSS 生产构建通过；这仍为模拟 Vault 证据，跨知识库实机导入未完成。

旧指纹兼容修复：导入、预检、恢复及内容读取按已存指纹前缀选择 FNV 或 SHA，避免支持 SHA 的新环境误判旧 FNV 历史。测试确认 SHA 环境可读取有效 FNV 内容，损坏 FNV 内容仍拒绝；全量检查通过。

快照内容完整性：复用已有 Blob 前比较完整内容，不一致时拒绝覆盖；读取 Blob 时核对指纹，损坏内容不会进入比较或恢复。测试覆盖有效重复写只落盘一次及损坏内容读写均停止。全量检查通过，实际磁盘损坏演练待验收。

自动快照读取一致性：读取及计算指纹后复核路径、对象身份、大小和修改时间，变化时拒绝记录；测试确认读取期间修改不会写入 Blob 或版本。元数据未变的外部写入仍不保证检出，真实同步并发读取待验收。

交付目录加载顺序：基础主页读取即登记有效交付路径，历史基线初始化先读取主页，不再依赖控制台先打开；越界及无父目录记录不参与排除登记。新增目录登记测试及全量检查通过，启动后旧交付目录快照排除仍需实机验证。

专注记录幂等测试：重复提交同一会话 ID 只保存一次，日统计分段只累计一次；持久记录保存独立对象，调用方之后修改原记录不改变统计。全量检查通过，真实计时完成及重载恢复仍待验收。

专注归属补充：开始计时前重新发现当前文件对应项目，不复用打开面板时的旧项目名称和位置快照。项目专注汇总只接受已完成或主动结束且时长有限非负的记录，测试确认异常数值及未知状态不污染统计。面板打开期间移动/改名的实机启动仍需验证。

监听生命周期行为补验：回调执行期间模拟销毁，后续回调不执行且不能重新登记监听；模拟防抖回调内创建同键新计时器，确认新计时器仍被跟踪；销毁后排队计时器不执行业务回调。全量检查通过，这些模拟不能代替 Obsidian 快速重载实测。

文件监听卸载保护：销毁后拒绝新增监听、防抖和派发；异步回调链每次调用前检查项目仍被监听。防抖触发时先删除旧计时器再调用回调，避免回调重入创建的新计时器被误清理。全量检查通过，快速切换项目及卸载仍需实机验证。

服务卸载保护：历史路径异步读取完成后检查服务是否已销毁，销毁后不新增项目监听；事件回调在开始及异步建立会话后检查状态，销毁入口幂等。历史恢复内部错误重新抛给启动反馈入口，修复此前内部捕获导致提示不可达的问题。全量检查通过，实际快速重载仍需验收。

历史错误传播补充：服务启动恢复历史跟踪及布局变化结束编辑会话的异步入口增加异常处理。历史初始化失败明确提示不可用且保留原数据，不再留下未处理 Promise 异常。全量检查通过，损坏索引实机启动提示仍需验证。

现有文件夹登记保护：损坏主页所在目录及其上下级不再被视为可登记空白目录；提交前确认选中目录对象仍然存在。登记提交与后续核对分开反馈，核对失败不误报登记失败。全量检查通过，损坏主页及移动中目录的登记界面仍需实机验证。

导入表单一致性修复：重新选择文件时独立副本选项与实际状态同时重置；异步旧文件读取结果不再覆盖新选择；提交期间禁用文件切换。导入成功与后续索引刷新分开反馈，刷新失败不会误报导入失败；关闭后丢弃未完成预检结果。全量检查通过，快速切换文件及失败反馈仍需实机验收。

属性编辑一致性：项目属性及任务编辑打开时保存独立数据快照，避免外部对象变更削弱过期表单比较。项目属性保存与后续页面刷新分开处理，刷新失败明确提示已保存。全量检查通过，两个窗口交叉编辑及刷新失败提示仍需实机验收。
